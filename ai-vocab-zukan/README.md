# AI用語ずかん

AI用語を「収集する図鑑」のように楽しく覚えられる単語帳アプリです。ビルド不要の静的サイト（HTML/CSS/JS）で、Vercel などの静的ホスティングにそのままデプロイできます。

## 機能

- **📖 図鑑タブ**: カードをタップするとめくれて、意味・「たとえるなら〜」という身近な例え話・実際の使用例が確認できます。覚えたら「収集する」ボタンでコレクション完了。図鑑グリッドには用語名と収集状況（●収集済み/○未収集）が一覧表示されます。カテゴリチップで絞り込みも可能です。
- **✏️ クイズタブ**: 用語を見て4択で意味を当てるクイズ。連続正解数とベスト記録を記録します。
- **9カテゴリ・128語収録**: 基礎 / 機械学習（学習・評価・高速化・MLOps系の実務用語を含む）/ 生成AI・LLM / 技術基盤 / マーケ・営業 / 副業スキル（Web制作・文字起こし系）/ 経理・事務 / 動画編集 / 画像・音声生成
- 進捗（収集状況・クイズのベスト記録）はブラウザの `localStorage` に自動保存されます。

## 使い方（ローカル確認）

ビルド不要の静的サイトです。

```bash
cd ai-vocab-zukan
python3 -m http.server 8000
# http://localhost:8000 を開く
```

## 構成

```
index.html        画面全体のレイアウト
css/styles.css     スタイル
js/data.js         カテゴリ・用語データ（用語の追加はここに追記するだけ）
js/app.js          図鑑・クイズのロジック
vercel.json        Vercel用の設定（静的サイトとして配信）
```

## 用語の追加・編集

`js/data.js` の `TERMS` 配列に、以下の形式でオブジェクトを追加するだけで図鑑・クイズ両方に自動反映されます。

```js
{ id: 'category-13', category: 'basics', term: '用語名', reading: '読み方', summary: '簡単な説明（カード表面）', analogy: 'たとえ話（カード裏面）', example: '使用例（カード裏面）' }
```

新しいカテゴリを追加したい場合は `CATEGORIES` 配列に `{ id, name, emoji, color }` を追加してください。

## デプロイ（GitHub → Vercel）

このリポジトリ全体はモノレポ構成のため、Vercel でインポートする際に **Root Directory** を `ai-vocab-zukan` に設定してください。

1. [Vercel](https://vercel.com) にログインし、「Add New... → Project」からこのGitHubリポジトリを選択
2. 「Root Directory」を `ai-vocab-zukan` に設定
3. Framework Preset は `Other`（ビルドコマンド不要）のままでOK
4. 「Deploy」をクリックすると数十秒でURLが発行されます

以降は `main`（またはこのアプリ用のブランチ）に push するたびに自動で再デプロイされます。
