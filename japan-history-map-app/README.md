# 日本史マップ 1600-現在

日本地図上のピンで、1600年(関ヶ原の戦い)から現在までの主な出来事を「いつ・どこで」起きたかを確認できる学習アプリです。あわせて、繰り返し学習・テストできるクイズ機能を備えています。

出来事の選定・用語は、文部科学省 学習指導要領(中学校社会・歴史的分野/高校 歴史総合・日本史探求)で扱われる標準的な範囲に沿っています(教科書そのものの文章は著作権保護のため使用していません)。

## 機能

- **地図で見る年表**: 日本地図上のピンをクリックすると出来事の詳細を表示。時代ボタン(江戸〜令和)・年代スライダー・カテゴリ(政治/戦争/外交/災害/経済/文化)で絞り込み可能。
- **クイズで復習**: 年号当て・場所当て・できごと当て・ミックスの4モード。間違えた問題は自動的に記録され、「苦手を復習する」で優先的に再出題(簡易間隔反復)。正答率などの学習記録はブラウザのlocalStorageに保存されます。

## 使い方

ビルド不要の静的サイトです。ローカルでプレビューする場合:

```bash
cd japan-history-map-app
python3 -m http.server 8000
# http://localhost:8000 を開く
```

そのまま GitHub Pages 等の静的ホスティングにもデプロイできます。

## 構成

```
index.html        画面全体のレイアウト
css/styles.css     スタイル
js/data.js         出来事データ・カテゴリ・時代の定義
js/map.js          簡略化した日本地図の描画とピン配置
js/app.js          地図タイムライン画面のロジック
js/quiz.js         クイズ機能のロジック
```

## 出来事データの追加・編集

`js/data.js` の `EVENTS` 配列に `{ id, year, title, pref, lon, lat, cat, desc }` の形式で項目を追加するだけで、地図・一覧・クイズすべてに自動反映されます。
