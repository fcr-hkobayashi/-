# 日本史マップ 縄文-現在

日本地図上のピンで、縄文時代(約1万3千年前)から現在までの主な出来事を「いつ・どこで」起きたかを確認できる学習アプリです。あわせて、繰り返し学習・テストできるクイズ機能を備えています。

出来事の選定・用語は、文部科学省 学習指導要領(中学校社会・歴史的分野/高校 歴史総合・日本史探求)で扱われる標準的な範囲に沿っています(教科書そのものの文章は著作権保護のため使用していません)。年代に諸説あるものは本文中に付記しています。

## 機能

- **地図で見る年表**: 日本地図上のピンをクリックすると出来事の詳細を表示。時代ボタン(縄文〜令和、全15時代)・年代スライダー(紀元前対応)・カテゴリ(政治/戦争/外交/災害/経済/文化)で絞り込み可能。同じ地点に出来事が集中する場合はピンを自動的に少しずらして表示し、重なりによるクリック不能を防いでいます。
- **クイズで復習**: 年号当て・場所当て・できごと当て・ミックスの4モード(紀元前の年号にも対応)。間違えた問題は自動的に記録され、「苦手を復習する」で優先的に再出題(簡易間隔反復)。正答率などの学習記録はブラウザのlocalStorageに保存されます。

## 使い方

ビルド不要の静的サイトです。ローカルでプレビューする場合:

```bash
cd japan-history-map-app
python3 -m http.server 8000
# http://localhost:8000 を開く
```

そのまま GitHub Pages 等の静的ホスティングにもデプロイできます。

## 構成

```
index.html        画面全体のレイアウト
css/styles.css     スタイル
js/data.js         出来事データ・カテゴリ・時代の定義
js/map.js          簡略化した日本地図の描画とピン配置
js/app.js          地図タイムライン画面のロジック
js/quiz.js         クイズ機能のロジック
```

## 出来事データの追加・編集

`js/data.js` の `EVENTS` 配列に `{ id, year, title, pref, lon, lat, cat, desc }` の形式で項目を追加するだけで、地図・一覧・クイズすべてに自動反映されます。`year` は西暦年を表し、紀元前は負の値(例: 紀元前660年 → `-660`)で指定します。時代区分は `ERAS` 配列で定義しています。
