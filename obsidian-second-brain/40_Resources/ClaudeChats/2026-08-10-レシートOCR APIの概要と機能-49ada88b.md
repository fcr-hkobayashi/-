レシートOCR APIとは、レシートや領収書の画像を送ると、そこに書かれた文字情報(店名・日付・金額・品目など)を自動で読み取ってテキストデータに変換してくれるWeb API(外部サービス)のことです。

**主な機能**
- 画像→テキスト変換(OCR: 光学文字認識)
- 店舗名、購入日、合計金額、税額、品目ごとの価格などを構造化データ(JSON形式など)で抽出
- 手書きの文字にもある程度対応するものもある

**代表的なサービス例**
- Google Cloud Vision API / Document AI
- AWS Textract
- Microsoft Azure AI Document Intelligence
- 国内サービス:LayerX、Dr.OCR、AI inside(DX Suite)など、日本のレシート形式に特化したもの

**使われる場面**
- 経費精算アプリ(手入力せずレシートを撮るだけで記録)
- 家計簿アプリ
- 会計ソフトとの連携

### **Claude**

いえ、レシート専用ではなく、どちらも汎用的な画像・文書解析APIです。レシートはその使い道の一つに過ぎません。

**Google Cloud Vision API**
- 画像全般に対応する汎用OCR・画像認識API
- 文字認識(OCR)だけでなく、物体検出、顔検出(感情の推定含む)、ラベル付け(画像に何が写っているか)、不適切コンテンツ検出なども可能
- 用途例:名刺の文字起こし、看板・標識の読み取り、写真の内容分類、ロゴ検出など

**Document AI**
- Vision APIより「構造化された文書」の解析に特化した上位サービス
- レシート以外に、請求書、契約書、身分証明書、履歴書など様々な文書タイプ向けの専用パーサー(解析モデル)が用意されている
- 例:「Invoice Parser」(請求書用)、「Receipt Parser」(レシート用)、「ID Proofing」(本人確認書類用)など、文書の種類ごとに最適化されたモデルを選べる

つまり「レシートを読み取りたい」ならDocument AIの中の「Receipt Parser」を使う、というイメージで、API自体は他の文書・画像処理にも幅広く使える汎用ツールです。
