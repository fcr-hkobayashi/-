Claude Codeは、ターミナルで使えるAnthropicのAIコーディングツールです。導入方法を紹介します。

## インストール方法(推奨:ネイティブインストーラー、Node.js不要)

**macOS / Linux**
```bash
curl -fsSL https://claude.ai/install.sh | bash
```

**Windows(PowerShell)**
```powershell
irm https://claude.ai/install.ps1 | iex
```

**Windows(WinGet)**
```
winget install Anthropic.ClaudeCode
```

インストール後、`claude --version` を実行してバージョンが表示されれば成功です。

## 認証

プロジェクトディレクトリで `claude` を実行すると、ブラウザが開いてログインを求められます。

- **Claude.aiアカウントでサインイン**(Pro/Maxプランなど、通常のClaude利用枠から消費)
- **APIキーを使う場合**:`platform.claude.com` でAPIキーを発行し、`ANTHROPIC_API_KEY` 環境変数に設定(従量課金)

## その他

- 従来の `npm install -g @anthropic-ai/claude-code` も使えますが、現在はネイティブインストーラーが推奨されています(Node.js不要のため)
- 困ったときは `claude doctor` で診断できます
- ターミナルを使わない場合は、デスクトップアプリ版もあります

OSやどんな用途で使いたいか(個人利用/チーム/API連携など)を教えていただければ、より具体的にご案内できます。
