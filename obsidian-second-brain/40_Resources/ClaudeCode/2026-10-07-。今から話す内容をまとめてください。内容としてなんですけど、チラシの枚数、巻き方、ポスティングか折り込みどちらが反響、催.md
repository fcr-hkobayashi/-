# 催事買取のチラシ施策 フィードバックまとめ

## 1. チラシ枚数
- **折り込みチラシ**: 1回の催事(4〜5日)で **1万部**。どの地域でも1万部で固定
- **ポスティング**: 地域によって枚数を変え、**約2,000枚**が目安。4日間で2,000枚、5日間で3,000枚など、期間に合わせて調整

## 2. 催事の日程と配布タイミング
- 開催は土日を含めた **木〜日(4日間)** または **木〜月(5日間)**
- **折り込み**: 金曜朝一または土曜朝一に配布
  - 1万部を1回で撒く場合と、1万部を2回に分けて撒く場合がある
- **ポスティング**: 初日の木曜(当日)に配布
- 「催事開始の何日前が一番反響が良いか」には、**明確な答えはありません**。当日〜開催期間中の配布が中心で、前倒しの配布は行っていません。

## 3. ポスティングの運用方法
- 当初は地域のタイミー(スポットワーカー)に委託していました。
- 品質にばらつきがあり、500枚の予定が100枚しか配られないなどの問題が出ました。
- そのため、**従業員によるキャッチ配布(手渡し)** に切り替えました。

## 4. 折り込みのエリア設定
- スーパー催事では、商圏が狭くなりがちです。
- そこで **最寄り駅から半径約5km以内** などと、エリアを絞って設定しました。

# 催事買取のチラシ施策 フィードバック(改訂版)

## 1. チラシの枚数
- **折り込みチラシ**: 枚数は地域の**世帯数**を基準に決めていました。1回の催事(4〜5日)で基本は1万部で、世帯数が多い地域は2万部にすることもありました。
- **ポスティング・キャッチ配布**: 地域によって枚数を変え、目安は約2,000枚です。4日間で2,000枚、5日間で3,000枚などに調整しました。

## 2. 配布タイミング
- 催事は**木〜日(4日間)または木〜月(5日間)**で開催しました。
- **折り込みは2回に分けると反響が一番良かった**です。
  - 1回目は開始日の木曜朝に1万部、2回目は2日後の土曜朝に1万部です。
  - 世帯数が少ない地域では、土日休みの人が多いため土曜朝を重視しました。
- ポスティングとキャッチ配布は、初日の木曜から行いました。
- 「何日前の配布が良いか」には明確な答えがありません。前倒しはせず、当日と期間中に配る形でした。
- 折り込みの配布日と部数は、**新聞折り込み所(販売店)ごとに事情が違う**ようです。同じ場所に重複して配ると意味がないので、折り込み所を調べて枠を押さえられると、より強くなります。当社ではこの手配を外部(キラクさん)に任せていたため、内容は浅いです。

## 3. 折り込みとポスティングのどちらが反響が良かったか
**地域によって逆の結果になりました。**

| | 折り込み | ポスティング・キャッチ配布 |
|---|---|---|
| **田舎(港町・漁師町)** | **反響が非常に高い** | (ほぼ使わず) |
| **都内** | **ほぼ来ない** | **折り込みより反響が高い** |

**田舎で折り込みが効いた理由**
- 買取店が周りになく、買取のチラシ自体が珍しいからです。
- 港町は車社会で、半径8〜10km圏に買取店があれば皆が行ける環境です。それでも、近くのスーパーに買取が来ると珍しがられて客数が増えました。
- 買取店が近くにないことが、一番重要な条件でした。

**都内で折り込みが効かなかった理由**
- 新聞折り込みに入る買取店のチラシは、田舎では1〜2枚、都内では5枚ほどあります。
- そのため、買取のチラシには慣れてしまい、気にしない人が多いです。当社の訴求が弱かった可能性もあります。
- 1枚1枚手渡しするキャッチやポスティングのほうが刺さりました。都内は店頭でもキャッチの粗利単価が高く、顔が見える接客が強いと考えています。

## 4. ポスティングの運用方法(委託からキャッチ配布へ)
- 当初は地域のタイミー(学生など)に委託していましたが、キャッチ配布(従業員が自ら配る)に切り替えました。
- 切り替え後のほうが、**経費まで含めた効率が良く**なりました。
  - その場で予約が取れます。
  - 商品の引き出しがしやすく、深いヒアリングができます。

**数字のイメージ**
- **委託ポスティング**: 500枚を5人で配って、来店は6〜7人、粗利は10〜15万円でした。
- **キャッチ配布**: 500枚配って、来店は確実に2〜3人でした。1人あたりの粗利は3〜5万円(合計で約6〜15万円)です。
- 人件費を含めて計算すると、**ミライアの業態ではポスティングを雇わないほうが良かった**です。

## 5. チラシの内容
- **目玉の買取品目**: イミテーション関連にしました。
- **期間表記**: 「10月1日〜5日限定」のように、期間限定で訴求しました。
- **クーポン**(3種類)
  - 最初は生活雑貨のプレゼントでした。
  - 米の価格が高かった時期は、お米のプレゼントにしました。
  - 買取成立のお客様に1,000円の商品券をプレゼントする形も使いました。
- **キャッチの声かけ**
  - 誰でも持っているものが強いです。おもちゃのアクセサリー(イミテーション)、昔集めたテレホンカード、使い切った香水などです。
  - 言いやすく、引き出しもしやすいです。

## 6. エリアの考え方と傾向
- スーパー催事は商圏が狭くなるため、最寄り駅から半径約5kmなどに絞りました(例: 秋葉原駅から半径5km)。
- 反響が良かった地域の共通点は、**目に付く場所で催事ができたこと**です。人通りが多い場所だと、毎日来る人が気になって来店します。そこから既存のお客様の口コミが広がり、「○○さんに言われて来た」という来店がとても多かったです。

## 7. キャッチ配布の運用
- 場所はスーパーの入口前です。スーパー側に許可を取り、**一番人が通る場所**で配りました。
- 時間帯は、お客様がいない間は**ほぼずっと**配っていました。

## 8. 失敗談(タイミー委託)
- 学生に配布を頼む際、「よろしくお願いします」としか伝えず、**ちゃんと配るように念押ししていなかった**ことが、配布ムラの一因です。
- 世帯数が少ない地域にもタイミーを多めに手配して、**チラシが余る**無駄が出ました。

## 補足: 「チラシ1枚あたりの反響率」とは
**反響率 = 反響数(来店・問い合わせ件数)÷ 配布枚数 × 100** です。たとえば1,000枚配って5人来れば0.5%です。「1枚で何人来るか」を見る指標で、媒体を比べるときに使います。

今回の数字を当てはめると、次のとおりです。

| 手法 | 配布枚数 | 来店数 | 反響率の目安 |
|---|---|---|---|
| 委託ポスティング | 500枚 | 6〜7人 | 約1.2〜1.4% |
| キャッチ配布 | 500枚 | 2〜3人 | 約0.4〜0.6% |

**確認したい点が2つあります。**
- 「500枚を5人で配った」は、5人合計で500枚(1人100枚)か、1人500枚ずつ(合計2,500枚)か。後者だと反響率は約0.3%になります。
- この数字だと、1枚あたりの反響率は委託のほうが高く見えます。ただ、キャッチ配布は1人あたりの粗利が高く、人件費もかからないため、効率が良かったという理解で合っていますか。

「反響数と配布枚数」が分かる折り込みの実績が1回分でもあれば、同じ式で反響率を出して、田舎と都内を比べられます。

#### Create PDF with Multiple Pages
```python
from reportlab.lib.pagesizes import letter
from reportlab.platypus import SimpleDocTemplate, Paragraph, Spacer, PageBreak
from reportlab.lib.styles import getSampleStyleSheet

doc = SimpleDocTemplate("report.pdf", pagesize=letter)
styles = getSampleStyleSheet()
story = []

# Add content
title = Paragraph("Report Title", styles['Title'])
story.append(title)
story.append(Spacer(1, 12))

body = Paragraph("This is the body of the report. " * 20, styles['Normal'])
story.append(body)
story.append(PageBreak())

# Page 2

story.append(Paragraph("Content for page 2", styles['Normal']))

# Build PDF
doc.build(story)
```

#### Subscripts and Superscripts

**IMPORTANT**: Never use Unicode subscript/superscript characters (₀₁₂₃₄₅₆₇₈₉, ⁰¹²³⁴⁵⁶⁷⁸⁹) in ReportLab PDFs. The built-in fonts do not include these glyphs, causing them to render as solid black boxes.

Instead, use ReportLab's XML markup tags in Paragraph objects:
```python
from reportlab.platypus import Paragraph
from reportlab.lib.styles import getSampleStyleSheet

styles = getSampleStyleSheet()

# Subscripts: use <sub> tag
chemical = Paragraph("H<sub>2</sub>O", styles['Normal'])

# Superscripts: use <super> tag
squared = Paragraph("x<super>2</super> + y<super>2</super>", styles['Normal'])
```

For canvas-drawn text (not Paragraph objects), manually adjust font the size and position rather than using Unicode subscripts/superscripts.
