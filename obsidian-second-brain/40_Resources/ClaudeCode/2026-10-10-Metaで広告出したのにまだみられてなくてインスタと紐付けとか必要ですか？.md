# Metaで広告出したのにまだみられてなくてインスタと紐付けとか必要ですか？

> Claude Code セッション記録（2026-10-10 〜 2026-10-10）。ツール実行ログは除外。

### **あなた**

Metaで広告出したのにまだみられてなくてインスタと紐付けとか必要ですか？

### **Claude**

結論から言うと、**Instagramとの紐付けは必須ではありません。** Facebookページだけでも配信はできます（Instagramには、そのページ名義で配信されます）。

紐付けが必要になるのは、次のような場合だけです。
- Instagramアカウント名義で広告を出したい
- Instagramの既存投稿をそのまま広告にしたい（ブースト）
- Instagramのプロフィールからのアクションを計測したい

## 配信されない場合に確認する点

広告マネージャで「配信ステータス」を見て、状態ごとに次を確認してください。

| 状態 | 原因と対処 |
|---|---|
| **審査中** | 通常は24時間以内ですが、数日かかることもあります。待つしかありません。 |
| **不承認・要対応** | 内容がポリシー違反の可能性があります。理由が表示されるので、修正して再申請します。 |
| **配信準備中・学習中** | 配信は始まっており、表示回数が出るまで時間がかかっています。 |
| **支払い方法の問題** | カード未登録、決済エラー、支出上限に達している場合は配信されません。 |
| **スケジュール** | 開始日時が未来になっていないか確認します。 |
| **予算・入札が低すぎる** | 日予算が数百円など少額だと、ほとんど表示されません。 |
| **ターゲットが狭すぎる** | 年齢・地域・興味関心を絞りすぎていると、配信対象が少なくなります。 |
| **アカウント制限** | ビジネス認証やアカウント品質の問題で停止されていることがあります。 |

「配信中」なのに表示回数が0の場合は、予算・ターゲット・入札のどれかが原因のことが多いです。

広告マネージャの配信ステータス（例：「審査中」「配信中」「不承認」など）を教えていただければ、原因をもう少し絞り込めます。
