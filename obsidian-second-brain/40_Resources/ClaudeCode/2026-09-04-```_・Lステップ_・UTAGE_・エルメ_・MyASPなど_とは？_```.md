# ``` ・Lステップ ・UTAGE ・エルメ ・MyASPなど とは？ ```

> Claude Code セッション記録（2026-09-04 〜 2026-09-04）。ツール実行ログは除外。

### **あなた**

```
・Lステップ
・UTAGE
・エルメ
・MyASPなど

とは？
```

### **Claude**

これらはすべて、**個人事業主・中小企業向けの「マーケティング自動化（MA）／販売導線づくり」のためのツール**です。ざっくり言うと「見込み客を集めて、メッセージを自動で送り、商品を売るまでの仕組み」を作るサービス群です。

大きく **2系統** に分けると分かりやすいです。

---

## ① LINE公式アカウントを拡張するツール（Lステップ・エルメ）

LINE公式アカウントだけだと機能が弱いので、それを**高機能化する外部ツール**です。

| ツール | 特徴 |
|--------|------|
| **Lステップ** | LINE配信ツールの最大手。友だちを属性で分けて、シナリオに沿って自動でメッセージを送る（ステップ配信）。アンケート・予約・タグ管理など高機能だが、やや高価格・上級者向け。 |
| **エルメ（L Message）** | Lステップの競合。**無料プランがある**のが最大の強みで、初心者・個人向け。機能はLステップに近く、コスパ重視の人に人気。 |

> ステップ配信＝「登録1日目にこれ、3日目にこれ…」と、あらかじめ組んだ順番で自動的にメッセージが流れる仕組み。

---

## ② メール／総合マーケティングツール（MyASP・UTAGE）

こちらは主に**メール配信**や**商品販売の仕組み全体**を作るツールです。

| ツール | 特徴 |
|--------|------|
| **MyASP（マイスピー）** | メール配信スタンド（ステップメール）の定番。メルマガ・決済・会員サイトなどを一括管理。「メールで売る」人の老舗ツール。 |
| **UTAGE（ウタゲ）** | 比較的新しい**オールインワン型**。LINE配信＋メール配信＋LP（ランディングページ）作成＋決済＋オンライン講座（会員サイト）まで、**1つで全部できる**のが売り。個別ツールを組み合わせる手間を省ける。 |

---

## まとめ（違いのイメージ）

```
LINEで売りたい         → Lステップ / エルメ
メールで売りたい       → MyASP
LINEもメールも全部一括 → UTAGE
```

- **エルメ** … 無料から始めたい初心者向けLINEツール
- **Lステップ** … 本格派・高機能なLINEツール
- **MyASP** … メール配信の定番
- **UTAGE** … 全部入りの新世代ツール

いずれも「集客 → 自動でフォロー → 販売」という**マーケティングの自動化**を実現するのが共通の目的です。
