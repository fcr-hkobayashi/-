# Macから別のMacへ全データを移す方法

## 方法1: 移行アシスタント（推奨・一番簡単）
新しいMacの初期設定時、または「アプリケーション > ユーティリティ > 移行アシスタント」で、旧Macからアプリ・書類・設定・ユーザーアカウントをまとめて移せます。

- 両方のMacを同じWi-Fiにつなぐか、Thunderbolt/USB-Cケーブルで直結します（ケーブルのほうが速いです）。
- 新しいMacで「Macから」を選び、旧Macに表示されたコードを確認します。
- 移したい項目（ユーザー、アプリ、その他のファイル、設定）にチェックを入れて開始します。

## 方法2: Time Machineバックアップから復元
旧Macを外付けドライブにTime Machineでバックアップします。新しいMacの設定時に「Time Machineバックアップから」を選んで復元します。

## 方法3: 手動コピー（必要なものだけ）
外付けSSDやiCloud Driveでファイルを移します。この場合、次のものも移し忘れに注意してください。

| 対象 | 場所 |
|---|---|
| 作業フォルダ | `~/Downloads/gigafile-0113-...` など |
| Claude Codeの設定・メモリ | `~/.claude/`（設定、メモリ、会話履歴） |
| シェル設定 | `~/.zshrc`、`~/.zprofile` |
| SSH鍵・Git設定 | `~/.ssh/`、`~/.gitconfig` |
| Homebrewのアプリ一覧 | 旧Macで `brew bundle dump` を実行 |

## 移行前のチェックリスト
- 旧Macで、iCloud、Apple ID、各種アプリ（Claude、Google Driveなど）のサインアウトや認証解除が必要なものを確認します。
- パスワードマネージャーやブラウザの同期がオンになっているか確認します。
- 新しいMacで確認が終わるまで、旧Macのデータは消さないでください。

## Claude関連の補足
Claudeのアカウント、コネクタ（Gmail、Slack、Notionなど）は、新しいMacでClaudeにログインし直せば使えます。ただし、このPCのローカル設定や記憶（`~/.claude/`）は自動では移りません。移行アシスタントを使えば一緒に移ります。手動の場合は、`~/.claude/` をコピーしてください。

## 移行アシスタント／Time Machineで移した場合
アプリ本体と設定も一緒に移るので、ほとんどのアプリは起動してログインし直すだけで使えます。ログインが切れているものだけ再ログインしてください。

## 手動で移す場合（新品のMacに入れ直す）
アプリ自体を再インストールしてからログインします。

- **App Storeのアプリ:** App Storeで同じApple IDにサインインし、「購入済み」から再ダウンロードします。
- **公式サイトのアプリ（Claude、Chromeなど）:** もう一度ダウンロードしてインストールし、ログインします。
- **Homebrew:** `brew bundle` で一括インストールできます。

## ログインだけでは戻らないもの
| 項目 | 対処 |
|---|---|
| ライセンス認証が必要な有料アプリ（Adobeなど） | ログイン後に認証します。旧Macでの認証解除が必要な場合があります。 |
| 2段階認証アプリ（Google Authenticatorなど） | 先にバックアップや引き継ぎ設定をします。移行前にしないと詰むことがあります。 |
| パスワードマネージャー | 新しいMacでログインすれば中身は同期されます。 |
| アプリ内のローカルデータ（ゲームの進行、オフラインのメモなど） | アプリによってはクラウドに保存されないので、データのコピーが必要です。 |
| Claude Codeのローカル記憶や設定（`~/.claude/`） | 手動の場合はコピーが必要です。 |
| ブラウザの拡張機能・ブックマーク | ブラウザの同期をオンにしてからログインします。 |

## 移行前にしておくこと
1. 2段階認証アプリの引き継ぎ準備をする。
2. ブラウザ、iCloud、パスワードマネージャーの同期がオンか確認する。
3. 旧Macのデータは、新Macで一通り確認が終わるまで消さない。

## 要注意（ログインだけでは戻らない）
| 項目 | 理由 | 対処 |
|---|---|---|
| **LINE** | トーク履歴は端末内に保存されます。ログインだけでは過去のトークが戻らないことがあります。 | 旧Macで先に「トーク履歴のバックアップ」を取ります。電話番号とメール登録の確認も必要です。 |
| **Obsidian** | ノート（Vault）はログインではなく、フォルダそのものです。 | Vaultのフォルダを丸ごとコピーします。Obsidian Syncを使っていれば同期でOKです。 |
| **Clipy**（クリップボード履歴） | 履歴と登録スニペットが端末内にあります。 | `~/Library/Application Support/Clipy` をコピーするか、設定からエクスポートします。 |
| **Typeless** | 辞書や設定がローカルにある可能性があります。 | アカウント同期の有無を確認します。無ければ `Application Support/Typeless` をコピーします。 |
| **Gyazo** | 画像はクラウドに残りますが、ローカルの保存データや設定は戻りません。 | 同じアカウントでログインし、設定を再確認します。 |
| **Dipper** | 設定が端末内にあります。 | 設定をスクショしておくか、エクスポートします。 |
| **GitHub Desktop** | ログインしても、ローカルのリポジトリ自体は戻りません。 | リポジトリのフォルダをコピーするか、再cloneします。未pushの変更が無いか先に確認してください。 |
| **SSH鍵 (`~/.ssh`)・Git設定 (`~/.gitconfig`)** | ログインでは戻りません。 | フォルダごと安全にコピーします（秘密鍵なので扱いに注意してください）。 |
| **Claude / Claude Code (`~/.claude`)** | ローカルの設定、メモリ、会話履歴は端末内です。 | `~/.claude` をコピーします。 |
| **作業フォルダ**（Downloads内のgigafile〜） | ファイルなのでログインでは戻りません。 | 手動でコピーします。 |
| **Chatwork** | 基本はクラウドですが、ローカル設定や通知設定は戻りません。 | ログインし直して設定を再確認します。 |
