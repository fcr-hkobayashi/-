## API連携できる可能性があるサイト

**eBay（海外オークション最大手）**が最も現実的な選択肢です。
- 公式の開発者ポータルがあり、Sell API / Browse API 等が一般公開されている
- **MCPサーバーも複数存在**：[YosefHayim/ebay-mcp](https://github.com/YosefHayim/ebay-mcp)（270エンドポイント対応の本格版）、[eBay公式のnpm-public-api-mcp](https://github.com/eBay/npm-public-api-mcp)、[CooKey-Monster/EbayMcpServer](https://github.com/CooKey-Monster/EbayMcpServer) など、Claude Desktop等ですぐ使える実装が複数公開されています
- 海外中古品・コレクター品の相場調査などをやりたいなら、事実上ここが一番手堅いです

**メルカリShops**は在庫連携・受注APIが提供されていますが、これは法人向けネットショップ機能（メルカリShops）向けで、一般ユーザーのフリマ出品・落札データにアクセスするものではありません。

## 難しいサイト

- **ヤフオク！**：Yahoo!デベロッパーネットワークにAPI群はあるものの、現状オークション出品・落札検索を自由に叩ける一般公開APIは見当たらず、Yahoo!ショッピング側（EC店舗運営向け）が中心です
- **駿河屋・じゃんぱら・モバオク・ラクマ・ジモティー**等：公式devAPIは見つからず、せどりツール等は基本的にスクレイピングベース（規約リスクあり）

## MCPという観点では

現時点でMCPサーバーが実際に存在し動くのは事実上**eBayのみ**です。日本の中古・オークション系サイトでMCP対応した公式・コミュニティ実装は見当たりませんでした（今後出てくる可能性はあります）。

オークファンで代替したい用途が「相場データ取得」なのか「出品/落札の自動化」なのかで最適解が変わるので、目的を教えてもらえればもう少し絞り込めます。

### **Claude**

「相場・出品データの検索のみ」という用途なら、**eBay公式のMCPサーバー（`@ebay/npm-public-api-mcp`）**が最適です。読み取り専用（GETのみ）で、かつ「アプリケーショントークンモード」を使えば、ご自身のeBayアカウントへのログインや同意フローも不要（Client ID/Secretだけで公開データにアクセス可能）です。

## ステップ1: eBay Developerアカウントの作成（ご本人での作業になります）

これはアカウント作成・本人確認を伴うため、私の方では代行できません。以下の手順でご自身で進めてください。

1. https://developer.ebay.com/ にアクセスし、右上の **Register / Sign In** から登録（既存のeBayアカウントでもOK、なければ新規作成）
2. ログイン後、[https://developer.ebay.com/my/keys](https://developer.ebay.com/my/keys) にアクセス
3. **Create an App Keys** で新しいアプリケーションを作成（アプリ名は任意、例: `soba-check`）
4. 発行される **Production** 環境の以下2つをメモ
   - `Client ID`（App ID）
   - `Client Secret`（Cert ID）
   - ※ `Dev ID` や `User Token` はこの用途（公開データ検索）では不要です

## ステップ2: 私がやること（Client ID/Secretをいただければ）

取得できたら、`Client ID` と `Client Secret` を教えてください。それを使って以下を設定します。

- プロジェクトに `.mcp.json`（または `claude mcp add` コマンド）でeBay MCPサーバーを登録
- `EBAY_TOKEN_TYPE=application` モードで設定（読み取り専用・公開データのみ、安全側の構成）
- Claude Codeを再起動すると `query_ebay_api` / `call_ebay_api` ツールが使えるようになり、eBayの商品検索・相場チェックができるようになります

Client Secretは機密情報なので、チャットに貼っていただいた内容はローカルの設定ファイル（あなたのマシン上のみ）に書き込み、外部には送信しません。取得できたら教えてください。
