# マキカエシ動画編集キット

## 🎯 ゴール（何が達成できたら完了か）
- 人の録音＋資料pptx＋台本を渡すだけで、**自分以外の人の Claude Code でも**
  同じ品質の教育動画（1920×1080 / 30fps）が書き出せること
- 手順書どおりに実行して**落ちない・黙って壊れない**こと

## 📌 現状・背景
- 実体は `~/Downloads/編集キット/`（配布用 zip は `編集キット_v1.1.zip`）。
  中身は `手順書.md` ＋ `scripts/`（Python 16本）＋ `assets/`（キャラ口パク3枚・ロゴ・BGM）
- 渡す相手には**フォルダごと渡し、手順書末尾の「丸投げプロンプト」を貼ってもらう**設計
- 案件（回）ごとに次の5点が別途必要。キットには入っていない:
  `台本.md` `テロップ用.md` `テロップ_スライド割.md` `資料.pptx` `音声.m4a`
- 処理の流れ: pptx→PNG → 音声を自然カット → 再ASR → テロップ時刻付け →
  サブスライドの時間割 → スライド層＋マーカー／キャラ口パく → 合成 → 冒頭を連結 → 機械検査
- 関連する資料側のルールは [[AI講座_資料作成・修正ルール]] と [[AI講座_スライドの言葉ルール]]
