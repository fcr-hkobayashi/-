# マキカエシ 検証版（受講者アプリ ⇄ 運営管理アプリ）セットアップ手順

受講者アプリ（叩き台 v0.5）と運営管理アプリを、Google スプレッドシートを間に置いてつなぐ検証用キットです。
**テスター数名・テスト用のデータでの検証に限って使ってください。**

## 中身

| ファイル | 役割 |
|---|---|
| `apps-script/Code.gs` | スプレッドシートの窓口（Apps Script）。受講者の保存・読み込み、運営の一覧・フィードバック・コード発行 |
| `student/index.html` | 受講者アプリ。v0.5 に「運営とつなぐ」「運営からのひとこと」を足したもの |
| `admin/admin.html` | 運営管理アプリ。運営キーを入れると実データを表示 |

## データの流れ

```
受講者アプリ ──（受講者コード＋同意）──▶ Apps Script ──▶ スプレッドシート
運営管理アプリ ──（運営キー）──────────▶ Apps Script ◀── 同じシートを読む
運営のフィードバック ──▶ シート ──▶ 受講者アプリの「運営からのひとこと」
```

---

## 1. スプレッドシートと Apps Script を用意する（10分）

1. Google ドライブで新しいスプレッドシートを作る（名前の例：`マキカエシ検証データ`）
2. メニューの **拡張機能 → Apps Script** を開く
3. 最初からある `コード.gs` の中身を消し、`apps-script/Code.gs` の中身をすべて貼り付けて保存
4. 上の関数選択で **`setup`** を選んで **実行**
   - 初回は権限の確認が出るので、自分のアカウントで許可する
5. 実行ログに出る **`ADMIN_KEY: ...`** を控える（運営キー。人に見せない）
6. スプレッドシートに `students` `me` `companies` `feedback` の4シートができていることを確認

## 2. Webアプリとして公開する

1. Apps Script の右上 **デプロイ → 新しいデプロイ**
2. 種類：**ウェブアプリ**
3. 次のユーザーとして実行：**自分**
4. アクセスできるユーザー：**全員**
5. デプロイして、表示される **ウェブアプリの URL**（`https://script.google.com/macros/s/.../exec`）を控える

> Code.gs を書き換えたときは、**デプロイを管理 → 編集 → バージョン「新バージョン」** で更新します。新しいデプロイを作り直すと URL が変わります。

## 3. 2つのアプリに URL を入れる

どちらのファイルも、`<script>` の最初にある次の1行を書き換えます。

```js
var API_URL = 'https://script.google.com/macros/s/xxxxxxxx/exec';
```

- `student/index.html` … 空のままなら v0.5 と同じ動き（端末保存のみ）
- `admin/admin.html` … 空のままならサンプル表示

## 4. 置き場所

- **受講者アプリ**：ゆうのリポジトリ（makikaeshi-prototype）の `index.html` を差し替える。
  **main に直接ではなく、ブランチ（例：`feature/sync-sheets`）を切ってプルリクエスト**で出す。Vercel のプレビュー URL で確認できる
- **運営管理アプリ**：同じリポジトリに `admin.html` として置けば、Vercel で `/admin` で開ける（vercel.json の cleanUrls が効く）
  - ページ自体は誰でも開けるが、運営キーがないとデータは出ない
  - 検索エンジンに載らないよう `noindex` を入れてある
- ※ claude.ai のアーティファクト上では外部への通信が止められるため、実データの接続はできない（サンプル表示のみ）

## 5. 動作確認の流れ

1. 運営管理アプリを開き、運営キーを入れて **読み込む**
2. 「受講者を追加する」で名前と期を入れて **発行する** → `MK-XXXXXX` が出る
3. 受講者アプリを開き、「運営とつなぐ」にコードを入れ、同意にチェックして **つなぐ**
4. 「あなたのこと」を書き、募集内容を貼って **この会社を保存する**
   - 1.5秒後に自動でシートに保存され、「運営とつながっています（最終保存 …）」と出る
5. 運営管理アプリで **最新にする** → 受講者が一覧に出る
6. 詳細でフィードバックを **記録する** → 受講者アプリを開き直すと「運営からのひとこと」に表示される

## 動きの決まり

- 運営がコードを発行した人しか書き込めない。同意にチェックしない限り保存されない
- 受講者アプリは、起動時にシートの内容を読み込み、端末に反映する（シートが正）
- 受講者が入力するたびに、1.5秒待ってまとめてシートに送る
- 運営管理アプリには、同意済みの受講者だけが表示される

## 検証版の限界（本番では作り直す）

| 項目 | 検証版 | 本番 |
|---|---|---|
| 受講者の本人確認 | 受講者コードのみ。コードを知っていれば、その人のデータを読める | ログイン（メール or LINEログイン） |
| 運営の本人確認 | 運営キー1つを共有 | 運営アカウントごとのログインと権限 |
| 同時書き込み | ロックで順番待ち。数十人規模まで | データベース（Supabase など） |
| 通知 | なし（LINE文面のコピーのみ） | LINE Messaging API |
| 規約 | 同意チェックのみ | 利用規約・プライバシーポリシー |

- 受講者コード・運営キーは LINE などで個別に渡し、グループには流さない
- 検証が終わったら、スプレッドシートのテストデータを削除する
- 実在の受講者の個人情報を入れる前に、竹人さん・上司と扱い方を決める
