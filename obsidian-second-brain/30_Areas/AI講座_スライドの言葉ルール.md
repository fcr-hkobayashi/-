# AI講座 スライドの言葉ルール

**結論：スライドに出る英字の専門用語は、台本と同じ「読み（カタカナ）」に直す。ただし `AI` はそのまま残す。**

「第2章 スライド_言葉_修正リスト」で毎回同じ判断を繰り返していたので、章ごとの一覧ではなく
**常設のルール**にした。新しい章の資料をつくる／直すときは、まずこれを当てる。

- 上位ルール：[[AI講座_資料作成・修正ルール]]（§2 化けやすい記号 / §3 略号は画面に出さない / §5 言葉）
  ※ 本部配布の規約そのもの。Vault 内に原文で取り込み済みなので、Downloads を整理しても参照は切れない。
- このノートは、その §3・§5 を**スライドの文字に対して機械的に適用できる形**に落としたもの。

---

## 1. なぜこのルールがあるか

- 対象者は**パソコンを触り始めた人**。画面に英字が出た時点で読めず、そこで止まる。
- 台本（音声）は「スキル」「ユーアールエル」と**読みで書いてある**。
  スライドだけ `skill` `URL` のままだと、**音声と画面がずれる**（＝検査で落ちる）。
- つまりこれは見た目の好みではなく、**音声↔画面の一致**の問題。

---

## 2. 置き換え辞書（これが本体）

| 画面に出ている文字 | 置換後 | 補足 |
|---|---|---|
| `skill` | スキル | |
| `URL` | ユーアールエル | |
| `CLAUDE.md` | クロード エムディー | 「エムディー」は半角スペースで区切る |
| `description` | ディスクリプション | |
| `.claude ／ skills` | スキルの置き場 | パス表記は通じない。**意味の分かる日本語へ言い換える** |
| `Web` | ウェブ | |
| `FB` などの略号 | （画面に出さない） | 音声・台本は元のままでよい |
| `AI` | **`AI` のまま** | → 3章「例外」参照 |

**置き換えたあとの後始末**

- 英字の前後にあった**半角スペースは詰める**。
  例：「は skill へ」→「はスキルへ」／「skill に同梱」→「スキルに同梱」
- 助詞ごと拾う。`URL を` → `ユーアールエルを`（`URL` だけ直すと「ユーアールエル を」になる）
- 括弧の中も対象。例：`（ファイル・貼り付け・URL・要点）` → `（ファイル・貼り付け・ユーアールエル・要点）`

---

## 3. 例外：`AI` は変えない

- 台本は全て「エーアイ」と書いてあるが、**スライドの `AI` は変えない**。
- 理由：アカデミー名「AI活用即戦力アカデミー」に含まれる**ブランド語**であり、
  スライド側は意図的に `AI` 表記にしている可能性が高い。
- 方針を変えたくなったら**本部に確認してから**。ここを勝手に一括置換しない。

---

## 4. あわせて必ず見る：化けやすい記号

次の記号はスライドの文字に使わない（環境によって化ける）。

| 使わない | 代わりに |
|---|---|
| 波ダッシュ `〜` | 全角 `～` にするか、図で描く |
| チェック `✓` | 図で描く |
| バツ `✗` | 図で描く |
| マイナス `−` | 図で描く |

- 区切りは**全角スラッシュ `／`**、進行の目盛りは **`N ／ M`** を使う。
- **検索では見つからない**（検索が記号を無視する）。**全ページの目視**でしか判定できない。
  最終判定は本部の版面検査に委ねる。

---

## 5. 作業のやり方（毎回この順で）

1. 対象フォルダのスライドを開き、**英字が出ている箇所を全部拾う**（章・デッキ・何枚目まで記録）。
2. 上の辞書で置換後の文字を決める。辞書に無い英字が出たら、**辞書にまず追記してから**直す。
3. 「スライド／現在の文字／置換後」の**3列の表**にして出す（＝反映指示書）。
   - 「現在の文字」は**その場に出ている通り**に書く（助詞・スペース込み）。本部がそのまま検索置換できる形にする。
4. 化け記号を目視で確認し、結果（0件でも）を書く。
5. `AI` の扱いに迷いが出たら、直さず**本部確認事項**として明記する。

### 反映の制約（既知）

Google スライドの本文テキストは、いまの Drive 連携では**こちら側から直接編集できない**
（タイトル・保存場所の変更のみ）。したがって成果物は**「置換表」までが基本**で、
反映は本部の工程で行う。直接反映したい場合は、Google スライド編集権のあるコネクタを
アカウント側で有効化してもらう必要がある。
