# AI講座 資料作成・修正ルール（協力メンバー向け）

> AI活用即戦力アカデミーの**動画スライドを作る／直す**ときのルール集です。**自分の Claude Code（や手元の作業）で作業できるよう、環境に依存しない形**でまとめました。できたものは本部（修正ルーム）に戻してください。検査・Drive反映・共有は本部がやります。**あなたは「体裁」「動き」「言葉」を守って中身を作るのが役割です。**

---

## 0. まず押さえる3つ

1. **1スライド＝言いたいこと1つ。** あれもこれも載せない。
2. **パソコンを触り始めた人・おじいちゃんおばあちゃんでも、一読で分かる言葉。** これが全ての基準。
3. **同じ絵で数十秒止めない。** 1つの話を2〜4枚に分け、要素を1つずつ出す（＝動き）。

---

## 1. 色（カラーコード）

| 名前 | HEX | 使うところ |
|---|---|---|
| 濃紺（メイン） | `#142A4F` | 題字・まとめ帯の背景・矢印・強い線 |
| 青（アクセント） | `#1F6FD8` | セクション名・下線・強調・囲み |
| 黒（本文） | `#1F242B` | 本文の文字 |
| 灰（弱い字） | `#7A8490` | 補足・注釈 |
| 罫線 | `#DDE3EA` | 区切り線・箱の枠 |
| 薄い背景 | `#F1F3F5` | 箱の塗り（グレー系） |
| 青みの薄背景 | `#EEF3FA` | いま注目させたい箱の塗り |
| 白 | `#FFFFFF` | 全体の背景 |

- **背景は白。基調は「濃紺＋青＋グレー」だけ。** 赤・緑・黄などの原色は使わない。
- 強調は「濃紺の帯」か「青の下線・囲み」で。**色数を増やさない。**

## 2. 文字（フォント）

- **Hiragino Sans（ヒラギノ角ゴシック）**。太字と普通を使い分け。
- サイズの目安: **題字 25pt / まとめ帯 19pt / 本文 17〜19pt / 補足 15pt**。**これより小さい字を本文に使わない。**
- **化けやすい記号は使わない**: 波ダッシュ `〜`／チェック `✓`／バツ `✗`／マイナス `−`。→ 全角（`～`）にするか、図で描く。

## 3. 1枚の作り（レイアウト）

```
┌──────────────────────────────────────────┐
│ セクション名(青・小)        セクション名  N ／ M │  ← 右上に進行の目盛り
│ 題字（濃紺・太・25pt・1〜2行）                 │
│ ──────────────────────────────────────── │
│ ［進行帯：よくある失敗 → … → やってみる の横並び］│
│                                           │
│   中央に「板書」＝箱・矢印・対比・簡単な図       │
│                                           │
│ ▌濃紺のまとめ帯（白文字・19pt）＝この1枚の結論   │
└──────────────────────────────────────────┘
```

- 左上に**題字**（濃紺・太字）。その上に小さくセクション名（青）。右上に**進行の目盛り**（例 `3 ／ 12`）。
- 下に**濃紺のまとめ帯**＝そのスライドで言いたいこと1つを白文字で短く。
- 中央は**箱・矢印・左右の対比・簡単な図**。**装飾のイラスト・写真・飾りは使わない（0）。**

## 4. 動きを出す（同じ絵で止めない）

**1つの話を2〜4枚に分け、要素を1つずつ足す。**

- 箇条を1つずつ出す／対比を「片側 → 両側」の順に出す／図が段階的に育つ（矢印・数字が後から現れる）。
- 前の絵と次の絵は、**足す1個以外は同じ**にする（続けて見ると動いて見える）。
- **新しい情報を足すのではなく、そのスライドが持つ要素を分けて順に見せるだけ。**

## 5. ★言葉のルール（いちばん大事）

**パソコンを触り始めた人・おじいちゃんおばあちゃんでも、一読で分かる言葉に。**

1. **遠回りしない。端的に。** 結論を先に、短く。「つまり何？」と思わせない。
   - 例: ×「工程が無いと二人で同じ場所をぐるぐる回り続ける」→ ○「これをしないと、いつまでも同じ間違いが返ってくる」
2. **題字は、パッと見て何の話か分かる言葉に。** かっこつけた言い回し・回りくどい表現にしない。
   - **AIを触ったことがない人にも通じるように。** 「また自分で直してませんか？」のような**AIを使った経験が前提の問い**は避け、「AIは、言わなければ同じ間違いを繰り返します」のような**事実の提示**にする。
3. **専門用語・カタカナ語・略号を使わない。** どうしても要るならその場でひとこと説明。
   - **略号（FB など）は画面に出さない**（音声・台本は元のままでよいが、スライドの文字にはしない）。
4. **硬い語をやわらかく**（値打ち→得／工数→手間／達成→クリア／「話が変わるたびに」→「新しく話しかけるたびに」）。
5. **チェック✓／バツ✗で「AIが悪い」に見せない。** 「人はこう／AIはこう」の**中立の対比**に（AIは"そういう性質"であって欠点ではない）。
6. **進行帯（上の目盛り）も分かりやすい言い方に**（例「なぜ繰り返す」→「なぜ繰り返すのか」／「抜け出す」→「どう抜け出すか」／「手を動かす」→「やってみる」）。
7. **抽象を数字・具体で**（「いつまでも同じ間違い」→「何十回でも同じ間違いが返ってくる」）。**ただし勝手に新しい数字を作らない**（元の台本の数字感に合わせる）。

## 6. 台本を「話し口調」にする場合

丁寧すぎる文は、読むと平坦になります。抑揚が出るよう、**内容は変えず、語り方だけ**話し言葉に。目指すのは「**塾の先生が、目の前の生徒に教えている話し方**」です（丁寧な朗読ではなく、面白い授業）。

### 崩し方（こうする）
- 「〜って」で主題化／「〜じゃないですか」／「〜と思います？」の問いかけ／「だから、」「要するに」で受け直す（「だから」は文をつながず、いったん切ってから置く）／「〜んですよね」で締める／「〜ちゃう」の縮約。
- **同じ形を続けない。言い切りと交互に。** フィラー（「まあ」「むしろ」「正直」、文頭の「あと」「で」）は使わない。
- **1文を短く。** ブロックの最後の1文は言い切りで終える（問いかけたまま切らない）。
- 若者言葉・流行語・雑な語は使わない（受講生は全職種・40代想定）。

### ★変えてはいけないもの（守らないと後工程で落ちます）
1. **意味・中身・順序** — 段落（ブロック）の数、各段落の言っていること、話の順番は1つも動かさない。
2. **長さ** — 各段落を、**元とだいたい同じ字数**に。話し言葉にすると増えがちなので、**長くしすぎない**（元の ±10% くらい）。
3. **決まった目印の文はそのまま** — 「ここで、手を動かします」「今日変えることは、1つだけです」「判定はここです」「この回は達成です」「クロードに頼むならこう言う」。これらは**1文字も変えない**。
4. **〈1秒あける〉などの間の指示** — 位置ごとそのまま残す。
5. **1行に1文**（話し言葉にしても1行に2文を入れない）。
6. **アルファベットを書かない** — 読みで書く（AI→エーアイ、Claude→クロード）。元の台本がその形なら、新しく英字を持ち込まない。
7. **最後の段落を後ろ向きな文で終わらせない。**
8. **その回で教えている中心の言い方**は言い換えない（他の回とのつながりが切れます）。

### 見本
本部の見本（第3章 3-1 の台本）が「正解の話し口調」です。迷ったら「3-1 ならどう言うか」で判断してください。**書き換えたら元の台本も残しておいてください**（比較用）。検査は本部がやります。

## 7. やってはいけない（まとめ）

- 装飾のイラスト・写真・飾りを載せる（箱・矢印・対比・簡単な図だけ）
- 色を増やす（濃紺・青・グレー以外）／小さい字を本文に使う
- 化ける記号（`〜` `✓` `✗` `−`）をそのまま打つ
- 専門用語・カタカナ語・略号・回りくどい長い文
- 1枚に情報を詰め込みすぎる／同じ絵で数十秒止める

## 8. 自分の Claude Code で作るときのプロンプト（そのまま貼れる）

```
教育動画のスライドを作ってください。対象は「パソコンを触り始めたばかりの人」で、
おじいちゃんおばあちゃんでも一読で分かる言葉にしてください。

【色・文字】
- 背景は白。基調色は 濃紺 #142A4F と 青 #1F6FD8 のみ。本文 #1F242B、弱い字 #7A8490、
  罫線 #DDE3EA、箱の塗り #F1F3F5 か 青みの #EEF3FA。赤・緑・黄などの原色は使わない。
- フォントは Hiragino Sans（ヒラギノ角ゴシック）。題字25pt・まとめ帯19pt・本文17〜19pt。
  これより小さい字は本文に使わない。
- 波ダッシュ〜・チェック✓・バツ✗・マイナス− は文字化けするので使わない。

【1枚の作り】
- 左上に題字（濃紺・太字）、その上に小さくセクション名（青）、右上に進行の目盛り（例 3／12）、
  下に濃紺のまとめ帯（白文字でこの1枚の結論）、中央は箱・矢印・左右の対比・簡単な図。
  装飾イラスト・写真・飾りは使わない。

【動き】
- 1つの話を2〜4枚に分け、要素を1つずつ足す（箇条を順に／対比を片側→両側／図が段階的に育つ）。
  前の絵と次の絵は、足す1個以外は同じにする。新しい情報は足さず、順に見せるだけ。

【言葉】
- 1スライド＝言いたいこと1つ。遠回りせず結論を先に短く。専門用語・カタカナ語・略号を使わない。
- 題字はパッと見て何の話か分かる言葉に。AIを触ったことがない人にも通じる事実の提示にする。
- チェック✓/バツ✗で「AIが悪い」に見せない（人はこう／AIはこう の中立の対比）。

作りたいスライドの内容：〔ここに「何を伝えるスライドか」を書く〕
```

## 9. できたものの戻し方

- 作った資料（PowerPoint／Google スライド／画像）と、どの回の何を作った/直したかのメモを、**本部（修正ルーム）に渡してください。**
- **検査（版面・文字化け・台本との一致）と、Drive／Google スライドへの反映は本部がやります。** あなたは体裁・動き・言葉のルールを守って中身を作るところまでで大丈夫です。
- 迷ったら、**本部の見本（第3章 3-1 の Google スライド）** を見てください。この体裁・動き・言葉が「正解の形」です。

## 10. 依頼プロンプト（自分の Claude Code に、このファイルと一緒に貼る）

**使い方**: 自分の Claude Code に、**この「AI講座 資料作成・修正ルール.md」を添付（またはリンクを渡し）**、下のプロンプトをコピーして貼り、〔　〕を自分の材料に置き換えて送ってください。

### ① 台本を話し口調に直してもらうとき

```
添付の「AI講座 資料作成・修正ルール.md」の §6 を読んでください。
そのうえで、下の台本を話し口調に直してください。

・§6 の「崩し方」で、内容は変えず、語り方だけ話し言葉に（「〜って」「〜じゃないですか」
  「だから、」「〜んですよね」など。同じ形は続けず言い切りと交互。フィラーは使わない）。
・§6 の「★変えてはいけないもの」を必ず守る（意味・順序・長さ〔元の±10%〕・決まった目印の文
  はそのまま・1行1文・アルファベットは読みで書く・後ろ向きに終わらせない・中心の言い方は
  言い換えない）。
・直す前の台本は消さず、別に残してください（比較用）。
・分からない言葉や判断に迷う所は、直さず「ここは確認」と印を付けて残してください。

直す台本：
〔ここに台本を貼る〕
```

### ② 資料を直してもらうとき（言葉を分かりやすく＋動きを出す）

```
添付の「AI講座 資料作成・修正ルール.md」を読んでください（特に §4 動き・§5 言葉・§7 禁止）。
そのうえで、下の資料を直してください。

・§5「言葉のルール」で、遠回りをやめて端的に／専門用語・カタカナ語・略号（FB など）をなくす／
  題字は、パッと見て何の話か分かる言葉に（AIを触ったことがない人にも通じる言い方に）。
・§4「動き」で、同じ絵で止めず、1つの話を2〜4枚に分けて要素を1つずつ出す
  （足す1個以外は前の絵と同じにする。新しい情報は足さない）。
・§1〜3 の体裁（色・文字・レイアウト・進行帯・まとめ帯）は崩さない。装飾イラスト・写真は使わない。
  化ける記号（〜 ✓ ✗ −）は使わない。
・中身（数字・名前・図の意味・話の順番）は変えない。変えるのは「見た目の言葉」と「見せ方」だけ。

直す資料：
〔いまの資料を貼る、または「どの回の資料か・どこが分かりにくいか」を書く〕
```

### ③ 新しく資料を1枚つくってもらうとき

→ **§8 のプロンプト**を使ってください。
