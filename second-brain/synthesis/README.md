# synthesis/ — weekly cross-vault reports

The weekly synthesis pass (the one pass that earns the premium model) writes
dated reports here: `YYYY-MM-DD-weekly.md`. Each one reads across the whole
graph and reports what changed, what's drifting, what deserves attention, and
what's missing.

This is analysis *about* the vault, not source material — it never goes in
`raw/`, and the agent doesn't compile from it.
