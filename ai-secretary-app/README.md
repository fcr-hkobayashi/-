# AI秘書メモ

運転中に話しかけるだけで、内容を自動で「仕事 / 新しいアイデア / 明日やること / 後で調べること」に振り分けて記録し、帰宅後にスマホでまとめて確認できるアプリです。ビルド不要の静的サイト（HTML/CSS/JS）で、Vercel などの静的ホスティングにそのままデプロイできます。

## できること（ロードマップの①〜③を実装）

1. **① 運転中の音声メモ** — 「話し始める」を1回タップすれば、あとは話すだけ。ブラウザの音声認識（Web Speech API）が一文ごとに自動でメモを保存する、ハンズフリー設計。保存時はバイブ・音声（「〇〇で保存しました」）で確認できるので、画面を見る必要はありません。
2. **② AIによる自動整理** — 保存時にキーワードベースの分類エンジンが「仕事 / 新しいアイデア / 明日やること / 後で調べること」に自動振り分け。Claude APIキーを設定すれば、「確認」タブでの要約をClaudeが自然な文章に書き直してくれます（任意・なくても動作します）。
3. **③ タスク化** — 「明日やること」に分類されたメモはチェックボックス付きのToDoとして扱えます。

「今日の運転中に考えたことまとめて」に相当する機能として、確認タブに **「今日のまとめをコピー」** ボタンがあり、

```
・仕事：〇〇
・新しいアイデア：〇〇
・明日やること：〇〇
・後で調べること：〇〇
```

の形式でクリップボードにコピーできます。

## 安全に関する注意

このアプリは運転中の「ながらスマホ」を助長する意図はありません。**画面操作は必ず走行開始前か停車中に行い**、走行中は音声のみでハンズフリー利用することを想定しています（画面の1回タップで開始→あとは声だけ）。

## 使い方（ローカル確認）

ビルド不要の静的サイトです。

```bash
cd ai-secretary-app
python3 -m http.server 8000
# http://localhost:8000 を開く
```

音声入力（マイク）はブラウザが `https`（またはlocalhost）でのみ許可するため、実機で試す場合はデプロイ後のURL（`https://...`）かlocalhostで確認してください。対応ブラウザはChrome系（Android含む）が中心で、Safariは対応状況が端末・バージョンによって異なります。未対応ブラウザでは自動的に手入力フォームのみが表示されます。

## 構成

```
index.html          画面全体のレイアウト（録音／確認／設定の3タブ）
css/styles.css       スタイル
js/classifier.js      キーワードベースの自動分類ロジック
js/storage.js         localStorageへの保存・読み込み
js/claude.js           Claude APIを使った任意の要約機能
js/app.js              画面の状態管理・音声認識・UIロジック
vercel.json            Vercel用の設定（静的サイトとして配信）
```

## データについて

メモはすべて **この端末のブラウザの `localStorage` だけ** に保存されます。サーバーには送信されません（Claudeで要約する場合のみ、その時だけAnthropicのAPIへ直接送信されます）。他の端末とは同期しないため、機種変更時は注意してください。

## 分類ロジックのカスタマイズ

`js/classifier.js` の `KEYWORDS` に単語を追加・編集するだけで、分類精度を調整できます。

## Claude APIによる要約（任意）

「設定」タブでAPIキー（[console.anthropic.com](https://console.anthropic.com/settings/keys) で発行）を登録すると、「確認」タブに「✨ Claudeで要約する」ボタンが表示されます。押すと、その日のメモをClaude（`claude-sonnet-5`）に送り、4分類の箇条書きとして整った要約を生成します。キーは `localStorage` にのみ保存され、ブラウザから直接Anthropic APIへ送信されます（バックエンドは経由しません）。

## デプロイ（GitHub → Vercel）

このリポジトリ全体はモノレポ構成のため、Vercel でインポートする際に **Root Directory** を `ai-secretary-app` に設定してください。

1. [Vercel](https://vercel.com) にログインし、「Add New... → Project」からこのGitHubリポジトリを選択
2. 「Root Directory」を `ai-secretary-app` に設定
3. Framework Preset は `Other`（ビルドコマンド不要）のままでOK
4. 「Deploy」をクリックすると数十秒でURLが発行されます

以降は `main`（またはこのアプリ用のブランチ）に push するたびに自動で再デプロイされます。
