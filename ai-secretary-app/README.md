# AI秘書メモ

運転中に話しかけるだけで、内容を自動で「仕事 / 新しいアイデア / 明日やること / 後で調べること」に振り分けて記録し、帰宅後にスマホでまとめて確認できるアプリです。ビルド不要の静的サイト（HTML/CSS/JS）で、Vercel などの静的ホスティングにそのままデプロイできます。

## できること（ロードマップの①〜③＋夜のLINEレポート・Notionアーカイブを実装）

1. **① 運転中の音声メモ** — 「話し始める」を1回タップすれば、あとは話すだけ。ブラウザの音声認識（Web Speech API）が一文ごとに自動でメモを保存する、ハンズフリー設計。保存時はバイブ・音声（「〇〇で保存しました」）で確認できるので、画面を見る必要はありません。
2. **② AIによる自動整理** — 保存時にキーワードベースの分類エンジンが「仕事 / 新しいアイデア / 明日やること / 後で調べること」に自動振り分け。Claude APIキーを設定すれば、「確認」タブでの要約をClaudeが自然な文章に書き直してくれます（任意・なくても動作します）。
3. **③ タスク化** — 「明日やること」に分類されたメモはチェックボックス付きのToDoとして扱えます。
4. **毎晩20時のLINE自動レポート（任意）** — 設定すると、保存したメモがサーバーにも同期され、毎晩20時(JST)にその日のメモをClaudeが要約してLINEに自動で送ってくれます。設定しなくてもアプリ本体は今まで通り動きます。
5. **Notionへの自動アーカイブ（任意）** — LINEレポートと同時に、その日のメモと要約をNotionデータベースに1ページとして自動保存します。検索できる記録として残るので、後から振り返りたいときに使えます。

「今日の運転中に考えたことまとめて」に相当する機能として、確認タブに **「今日のまとめをコピー」** ボタンがあり、

```
・仕事：〇〇
・新しいアイデア：〇〇
・明日やること：〇〇
・後で調べること：〇〇
```

の形式でクリップボードにコピーできます。

## 安全に関する注意

このアプリは運転中の「ながらスマホ」を助長する意図はありません。**画面操作は必ず走行開始前か停車中に行い**、走行中は音声のみでハンズフリー利用することを想定しています（画面の1回タップで開始→あとは声だけ）。

## 使い方（ローカル確認）

ビルド不要の静的サイトです。

```bash
cd ai-secretary-app
python3 -m http.server 8000
# http://localhost:8000 を開く
```

音声入力（マイク）はブラウザが `https`（またはlocalhost）でのみ許可するため、実機で試す場合はデプロイ後のURL（`https://...`）かlocalhostで確認してください。対応ブラウザはChrome系（Android含む）が中心で、Safariは対応状況が端末・バージョンによって異なります。未対応ブラウザでは自動的に手入力フォームのみが表示されます。

## 構成

```
index.html               画面全体のレイアウト（録音／確認／設定の3タブ）
css/styles.css            スタイル
js/classifier.js           キーワードベースの自動分類ロジック
js/storage.js              localStorageへの保存・読み込み
js/claude.js                Claude APIを使った任意の要約機能（確認タブの手動要約用）
js/sync.js                  保存時にサーバー(/api/entries)へバックグラウンド同期する（任意）
js/app.js                   画面の状態管理・音声認識・UIロジック
api/entries.js              メモをKVに保存・取得するAPI（LINEレポート用）
api/cron/daily-report.js    毎晩20時に自動実行され、Claudeで要約してLINE送信・Notion保存を行う
lib/kv.js                    Vercel Storage(Upstash Redis)のREST APIラッパー
lib/date.js                  日本時間の日付キーを作るヘルパー

lib/notion.js                 Notion APIへの1日1ページ保存
vercel.json                  Vercel用の設定（静的配信＋Cron設定）
```

## データについて

メモは基本的に **この端末のブラウザの `localStorage`** に保存されます。サーバーには送信されません（Claudeで要約する場合のみ、その時だけAnthropicのAPIへ直接送信されます）。他の端末とは同期しないため、機種変更時は注意してください。

保存したメモは自動的にサーバー（Vercel Storage）にも同時に送られます（同期用の合言葉はコードに組み込み済みで、追加設定は不要です）。これは夜のLINEレポート・Notion保存を作るためだけに使われます。

## 分類ロジックのカスタマイズ

`js/classifier.js` の `KEYWORDS` に単語を追加・編集するだけで、分類精度を調整できます。

## Claude APIによる要約（任意）

「設定」タブでAPIキー（[console.anthropic.com](https://console.anthropic.com/settings/keys) で発行）を登録すると、「確認」タブに「✨ Claudeで要約する」ボタンが表示されます。押すと、その日のメモをClaude（`claude-sonnet-5`）に送り、4分類の箇条書きとして整った要約を生成します。キーは `localStorage` にのみ保存され、ブラウザから直接Anthropic APIへ送信されます（バックエンドは経由しません）。

## デプロイ（GitHub → Vercel）

このリポジトリ全体はモノレポ構成のため、Vercel でインポートする際に **Root Directory** を `ai-secretary-app` に設定してください。

1. [Vercel](https://vercel.com) にログインし、「Add New... → Project」からこのGitHubリポジトリを選択
2. 「Root Directory」を `ai-secretary-app` に設定
3. Framework Preset は `Other`（ビルドコマンド不要）のままでOK
4. 「Deploy」をクリックすると数十秒でURLが発行されます

以降は `main`（またはこのアプリ用のブランチ）に push するたびに自動で再デプロイされます。

## 夜8時のLINE自動レポートを有効にする（任意）

すべて設定しなくてもアプリ本体（録音・自動分類・タスク化）は今まで通り使えます。LINEレポートが不要ならこの節は飛ばしてOKです。

### 1. LINEでBotを作る（LINE Notifyは終了しているため、代わりにMessaging APIを使う）

1. https://developers.line.biz/ja/ にログインし、「コンソールへ」→ プロバイダーを新規作成（名前は自由）
2. 作成したプロバイダー内で「チャネルを作成」→ **Messaging API** を選択し、必要事項を入力して作成
3. チャネルの「Messaging API設定」タブ下部にある **「チャネルアクセストークン（長期）」** を発行し、値を控えておく
4. 同じタブ上部のQRコードを自分のLINEアプリで読み取り、Botを友だち追加する（これで自分だけが友だちのBotになる）

### 2. Vercelでデータベース（Storage）を作る

1. Vercelのプロジェクト画面の左メニュー「ストレージ」→ データベースを作成（Upstash for Redis / KV 系のものを選択）
2. 作成したデータベースを、このプロジェクトに **Connect（接続）**
   - 接続すると `KV_REST_API_URL` / `KV_REST_API_TOKEN` などの環境変数が自動で追加されます（名前が多少違う場合はそのまま使ってください。コード側は `KV_REST_API_URL` と `KV_REST_API_TOKEN` を参照します）

### 3. Vercelに環境変数を追加する

プロジェクトの「設定」→「環境変数」で、以下を追加します。

| 変数名 | 値 |
|---|---|
| `LINE_CHANNEL_ACCESS_TOKEN` | 手順1で発行したチャネルアクセストークン |
| `ANTHROPIC_API_KEY` | Claude APIキー（[console.anthropic.com](https://console.anthropic.com/settings/keys)で発行。夜のレポート生成専用で、確認タブの手動要約とは別物） |
| `SYNC_SECRET` | `js/sync.js`内の`HARDCODED_SECRET`と同じ値にしてください（コード内を検索すれば見つかります）。アプリ側での追加入力は不要です |
| `CRON_SECRET` | （推奨・任意）自分で決めた合言葉。設定するとVercelのCronからの呼び出し以外を拒否できます |

追加後、変更を反映するために **一度再デプロイ**してください（「デプロイメント」タブから最新のものを「Redeploy」）。

### 4. 動作確認

- 毎晩20:00(JST)に自動実行されますが、Vercelの仕様上、数分前後する場合があります
- 今すぐテストしたい場合は、Vercelプロジェクトの「Cron Jobs」画面から手動実行（Run）できます
- その日のメモが1件もない場合も「メモはありませんでした」という通知が届きます（不要ならCronジョブを一時的に無効化してください）

### 制限・注意点

- Vercelの無料プラン（Hobby）でもCron Jobsは使えますが、実行タイミングに数分の誤差が出ることがあります
- オフライン中に保存したメモはサーバーへの同期に失敗することがあります（この端末には残りますが、その日のLINEレポートには反映されない場合があります）
- `SYNC_SECRET`はブラウザのJavaScriptに埋め込まれているため、悪意ある第三者への完全な防御にはなりません（本人以外がURLを知らない前提の簡易的な保護です）。**このURLを他人に共有すると、その人が保存したメモも同じデータベース・同じLINEレポートに混ざります**（ユーザーごとの分離機能はありません）ので、共有しないでください

## Notionへの自動アーカイブを有効にする（任意）

毎晩のLINEレポートと同時に、その日のメモをNotionのデータベースに1ページとして保存します。LINEレポートの設定（上記）が完了していることが前提です。

### 1. Notionに保存先データベースを用意する

「AI秘書メモ」という名前のデータベースを、日付・仕事・新しいアイデア・明日やること・後で調べること・メモ件数の列で作成してください（Notion内で手動作成でも、Claudeに頼んで作成してもらってもOKです）。

### 2. Notionの連携（インテグレーション）を作る

1. https://www.notion.so/my-integrations にアクセスし、「+ New integration」
2. 名前（例:「AI秘書メモ」）を付けて、対象のワークスペースを選択して作成
3. 「Internal Integration Secret」を発行・コピー（`ntn_...`のような文字列）
4. 保存先データベースのページを開き、右上の「...」→「Connections」→ 作成したインテグレーションを追加（これで書き込み権限が付与されます）
5. データベースのURL（`https://www.notion.so/xxxxxxxx?v=...`の`xxxxxxxx`の部分、32桁の英数字）を控えておく

### 3. Vercelに環境変数を追加する

| 変数名 | 値 |
|---|---|
| `NOTION_TOKEN` | 手順2で発行したInternal Integration Secret |
| `NOTION_DATABASE_ID` | 手順2で控えたデータベースID |

追加後、**再デプロイ**してください。設定されていない場合、Notion保存は自動的にスキップされ、LINEレポートには影響しません。
