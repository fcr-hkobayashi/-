# 完成イメージ（基準）— 「動画を編集して」と言われたらこの型で作る

2026-10-02 にユーザーが指定。参考動画は `references/ref_A_freelance.mp4`（49秒）と `references/ref_B_fukugyo.mp4`（56秒）。
動画ファイルは第三者の広告なので Git には入れない（ローカルのみ）。参考にするのは**型**であり、文言・素材は流用しない。

## 型の要約
**「ナレーション（声のみ）＋ 日常シーンのBロールを約2秒ごとに切り替える体験談風ショート（50秒前後）」**
顔出しのしゃべりではなく、1フレーズ＝1カットで映像を当てていく。

## 構成（約50秒）
| 区間 | 内容 | 参考A | 参考B |
|---|---|---|---|
| 0〜3秒 | フック（結果を先に言う） | 「元接客業がフリーランスになった結果…」 | 「現場仕事の俺が"帰宅後の2時間"で副業を始めた結果…」 |
| 〜35秒 | 本編 | ①〜⑤のメリット列挙（見出しラベル付き） | 結果 → 過去の苦労 → 出会い → 支援内容 |
| 35〜45秒 | 共感・転換 | 黒画面「前の私みたいに」→「…って思ってる人」 | 黒画面「実は俺、」「副業始める前は」 |
| 最後5〜10秒 | CTA | スマホで LP を操作＋「まずはこの診断だけでも受けてみて」 | iPad で LP を操作＋「まずは1分のタイプ診断だけでもやってみて」 |

## 編集の数値
- 尺 49〜56秒 / カット 24〜29個（**平均約2秒**、冒頭はやや短め）/ 転換エフェクトなし（ハードカットのみ）
- 音: ナレーション＋**BGM が全編に途切れず流れる**（無音区間なし）。最終ラウドネス -14〜-19 LUFS
- 画面: 9:16、Bロールは手持ち・生活感のある実写（部屋・PC・食事・移動・手元）

## テロップ
- **位置は画面中央**（縦 約45〜55%）。白文字・太ゴシック・やわらかい影（太いフチは使わない）
- 1〜2行、1行 約10〜14字。ナレーションとほぼ同じ文言のフルテロップ
- **フック（B）**: 画面中央に黒帯、白＋黄＋赤の大きな文字、3行
- **見出しラベル（A）**: 「①毎日好きなだけ寝れる😴」のようなピンクの角丸ラベルを、その話題のあいだ出し続け、下に字幕
- **黒画面カード**: 黒背景に白文字1行。場面転換・感情の切り替えに使う
- **CTA**: 角丸ボックス（Aはピンク、Bは白地に黒の大文字）で中央に大きく
- 絵文字を適度に使う（A）

## 常時表示
- 左上に小さく**打消し表示**（例「※サポートは役務提供期間内に限ります」「※成果を保証するものではありません」）
  → みらいや版では「※買取価格は商品の状態・相場により変動します」など

## みらいや版に置き換えるときの注意
- 体験談風にする場合は**実在のスタッフ／お客様の実話**だけ（AI人物に体験談を語らせない。景品表示法）
- 金額・実績は根拠資料があるものだけ。打消し表示は読める大きさで常時表示
- LP の代わりに「LINE査定」「予約ページ」などの画面録画を締めに使う
