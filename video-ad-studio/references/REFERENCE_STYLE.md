2026-10-02 にユーザーが指定。基準は2つの型。**素材で選ぶ**:
- 話している本人の実写がある → **型2：本人語り（CR25）**

# 型1：ナレーション＋Bロール（参考A・B）

## 型の要約
**「ナレーション（声のみ）＋ 日常シーンのBロールを約2秒ごとに切り替える体験談風ショート（50秒前後）」**
顔出しのしゃべりではなく、1フレーズ＝1カットで映像を当てていく。

## 構成（約50秒）
| 区間 | 内容 | 参考A | 参考B |
|---|---|---|---|
| 0〜3秒 | フック（結果を先に言う） | 「元接客業がフリーランスになった結果…」 | 「現場仕事の俺が"帰宅後の2時間"で副業を始めた結果…」 |
| 〜35秒 | 本編 | ①〜⑤のメリット列挙（見出しラベル付き） | 結果 → 過去の苦労 → 出会い → 支援内容 |
| 35〜45秒 | 共感・転換 | 黒画面「前の私みたいに」→「…って思ってる人」 | 黒画面「実は俺、」「副業始める前は」 |
| 最後5〜10秒 | CTA | スマホで LP を操作＋「まずはこの診断だけでも受けてみて」 | iPad で LP を操作＋「まずは1分のタイプ診断だけでもやってみて」 |

## 編集の数値
- 尺 49〜56秒 / カット 24〜29個（**平均約2秒**、冒頭はやや短め）/ 転換エフェクトなし（ハードカットのみ）
- 音: ナレーション＋**BGM が全編に途切れず流れる**（無音区間なし）。最終ラウドネス -14〜-19 LUFS
- 画面: 9:16、Bロールは手持ち・生活感のある実写（部屋・PC・食事・移動・手元）

## テロップ
- **位置は画面中央**（縦 約45〜55%）。白文字・太ゴシック・やわらかい影（太いフチは使わない）
- 1〜2行、1行 約10〜14字。ナレーションとほぼ同じ文言のフルテロップ
- **フック（B）**: 画面中央に黒帯、白＋黄＋赤の大きな文字、3行
- **見出しラベル（A）**: 「①毎日好きなだけ寝れる😴」のようなピンクの角丸ラベルを、その話題のあいだ出し続け、下に字幕
- **黒画面カード**: 黒背景に白文字1行。場面転換・感情の切り替えに使う
- **CTA**: 角丸ボックス（Aはピンク、Bは白地に黒の大文字）で中央に大きく
- 絵文字を適度に使う（A）

## 常時表示
- 左上に小さく**打消し表示**（例「※サポートは役務提供期間内に限ります」「※成果を保証するものではありません」）
  → みらいや版では「※買取価格は商品の状態・相場により変動します」など

## みらいや版に置き換えるときの注意
- 体験談風にする場合は**実在のスタッフ／お客様の実話**だけ（AI人物に体験談を語らせない。景品表示法）
- 金額・実績は根拠資料があるものだけ。打消し表示は読める大きさで常時表示
- LP の代わりに「LINE査定」「予約ページ」などの画面録画を締めに使う

# 型2：本人語り・ひとり対談（参考C：CR25）

## 型の要約
**出演者が1人で「相談者」と「コーチ」を演じ分け、相談 → 指摘 → 再定義 → 自分の経歴 → CTA と語る実写（約65秒）**
三脚固定のカメラ目線＋手前に本を積んだ小道具。カットは**ジャンプカット＋デジタルズームの寄り引き**で約2秒ごとに変化をつける。

## 構成（約65秒）
| 区間 | 内容 |
|---|---|
| 0〜6秒 | 相談者役で「ふるげんさん！今の仕事…全然おもしろくなくて」（ひとり対談の導入） |
| 6〜20秒 | コーチ役「何したいか決まってます？」→ 相談者の本音（言いかけては取り消す） |
| 20〜30秒 | 指摘「今2回消しましたよね？」「ご自身で取り消してます」「それ、いい人ほどやるんです」 |
| 30〜37秒 | 再定義「強みとは、あなたがやって当たり前だと思っていること…」 |
| 37〜48秒 | 自分の経歴（教壇→営業・事業構築・マネジメント、2.4億、30億企業の執行役員）＋**実写の写真を1秒ずつ挿入** |
| 48〜54秒 | 「強みが言葉になると、順番が変わります」「やり方を探していた人が、行き先から選ぶようになる」 |
| 54〜65秒 | CTA（話すだけでいい → LINE で無料相談 → ワークシート配布中 → 次の一手を一緒に） |

## 編集の数値
- 1080×1920・29.97fps・65秒 / シーン変化 33回（ジャンプカット・寄り引き・写真挿入）/ 転換エフェクトなし
- 音: 本人の声が主体。最終ラウドネス約 -22 LUFS（→ 当スタジオでは -14 LUFS にそろえる）

## テロップ（型1より演出が多い）
- **基本**: 画面中央やや下（縦 約50〜60%）、白文字＋黒の縁取り。話し言葉をそのままフルテロップ
- **強調語は黄色**（「30万」「自分が納得」「世の中の役に立つような仕事」）、**数字は大きく黄色**（「2.4億」「30億」）
- **感情の山場は色を変える**: 「今2回消しましたよね？」＝赤、「ご自身で取り消してます」＝紫＋**映像をモノクロに**
- **縦書きテロップ**: 相談者の言葉の引用は、画面の端に**金色の帯つき縦書き**（「いい格好をする言い方になってしまうんですけど」）。否定の言葉は**赤い帯の縦書き**（「感謝されなくてもいいんだけど」）
- **キーメッセージは大きな黄色の縦書き**（「あなたがやって当たり前だと思っていること」「強みが言葉になると／順番が変わります」）
- **CTA**: 赤い角丸ボックス「画面下のリンクから無料相談にお越しください！」＋黄色の下向き矢印3つ（↓↓↓）。特典は**画像カード**（ワークシートの表紙）＋黄色の縦書き「才能発見ワークシートを配布中」
- 締めは黄色の縦書き「あなたの『次の一手』を一緒に見つけにいきましょう」

## 写真の挿入
- 経歴を話す場面で、本人の実際の写真（教壇・家族・生徒との写真）を1秒ずつ全画面で挿入
- 写っている第三者の顔はぼかす

## 当スタジオで再現するとき
- `ad all`（実写カット）に、デジタルズーム（1.0／1.32／1.62倍）・縦書きテロップ・色替え・モノクロ演出・写真挿入・CTA ボックス＋矢印を足して作る
- 台本シートの「冒頭3秒①〜③」は、冒頭だけ差し替えた別バージョンとして書き出す
