# 演出設計（印象 → フォント・効果音・アニメーション）

2026-10-04 上司の指示。**「こういう結果・テロップ・編集にしたい」という完成形を、言語化・プロンプト化して AI に渡す。**
台本の1文ごとに「相手に与えたい印象」を決め、それに合う音声・フォント・効果音・アニメーションを割り当てる。
作って→AI に投げて→検証→直す、を繰り返して完成させる（プロンプト自体も育てる）。

## 手順
1. 台本（文字起こし）を1文ずつに分ける
2. 各文に **印象** をつける（下の表。迷う文は「ユーザーに聞く」に回す）
3. 印象ごとの **演出プリセット**（フォント・色・SE・アニメ・間）を割り当てる → `projects/<name>/edit/direction.json`
4. ユーザー承認 → compose に反映 → 書き出し → `ad qa` で検証 → 差分をプリセットに還元

## 印象の軸
| 軸 | 値 |
|---|---|
| 感情の向き | ポジ / ネガ / ニュートラル |
| 強さ | 弱 / 中 / 強 |
| 役割 | フック / 共感 / 転換（どん底→回復）/ 実績・数字 / 根拠 / CTA |

例（上司の例）:
- 「僕も最初どん底だった」→ **ネガ・共感（どん底）**。暗め・小さめ・間を置く・低い効果音（または無音）
- 「今では副業で16万円」→ **ポジ・実績**。数字を大きく強調色、ポップ・上昇系の効果音、スケールイン
- ネガ→ポジの切り替わりは **転換** として、間・黒画面・色替えで落差を作る

## 演出プリセット（初期案・要検証。実際の値は brand.json / sfx / fonts に合わせて調整）
| 印象 | フォント | 色 | 効果音 | アニメーション | 間 |
|---|---|---|---|---|---|
| ネガ・共感 | 細め（Noto Sans JP） | 白〜グレー | 低音/無音 | ゆっくりフェード | 前後に 0.3〜0.5秒 |
| ポジ・実績（数字） | 極太（M PLUS 1p Black） | 黄/赤の強調 | ポップ・上昇音 | スケールイン＋バウンド | 数字で一瞬止める |
| フック | 極太 | 赤黄 | インパクト音 | 即表示・揺れ | なし |
| 転換 | 中太 | 白→強調色 | 切替音 | 黒画面カード | 0.5秒 |
| CTA | 極太 | 赤＋矢印 | 決定音 | ポップ＋矢印点滅 | 長めに表示 |
