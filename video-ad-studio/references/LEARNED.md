## 20261004-chaen-claudecode-edit — チャエン「Claude Code・Codex での動画編集手法」
- 出典: https://x.com/masahirochaen/status/2106375997373468856 （チャエン｜デジライズ CEO、約14分の解説動画）
- 上司がこの動画を共有。上司の依頼＝「僕が Twitter や動画を送るので、自動で学習してほしい」
- 実物: `references/learn/20261004-chaen-claudecode-edit/`（video.mp4・transcript.txt・contact.jpg・frames/）

### 一言要約
撮影した動画を AI（Claude Code / Codex）に渡すだけで、カット・字幕・縦型ショート化・ニュース動画まで自動で作る。
外注（1本3〜5万円×月20本＝約100万円）をゼロにした。肝は「**編集の手順書＝スキル**」と「**API を繋ぐハブとしての Claude Code**」。

### 仕組み（私たちの `ad` パイプラインとほぼ同じ発想）
- Claude Code / Codex が**スキル（編集ルール・工程順・実行コード）**を読み、道具を順番に動かす。人がやるのは「最初の設定・素材と好みを伝える・最後の確認」
- 道具: 文字起こし＝Whisper（無料だが精度が低め→ Gemini 系に変更）／映像生成＝Seedance 2.5／画像＝OpenAI 画像生成／
  音声＝ElevenLabs→安い Gemini 3.8 TTS／図解＝Manim／合成・アニメ＝HyperFrames＋Python／仕上げ＝Premiere Pro へ XML・SRT で書き出し
- 3つのルート: ①撮った動画→字幕付き長尺（約24分でカット202箇所・字幕588枚）②長尺→縦型ショート（20〜30分→1〜2分）③原稿・素材→ニュース動画（冒頭数秒だけ映像生成AI）
- スキルは用途ごとに分けて複数作る（長尺編集／ショート切り抜き／ニュース…）。**よく使うものは全部スキル化**
- ジャンプカット・字幕改行の判断は AI（たまにミスるが許容範囲）。字幕は**意味のまとまりで2行**に整える
- 検証: e2e で全フレームをスクショさせてズレを確認（トークンを使うが品質が上がる）
- **プロに作ってもらったサンプルを1本用意して「それ通りにやって」と指示するとほぼコピーできる**（← 上司の「完成形を言語化」と同じ考え方）
- 「Xのリンクを貼って、過去に作った動画を参考にやっておいて」だけでショートが出来た＝参考の自動学習が成立している
- APIモデルが進化すれば動画の質も上がる（モデル差し替えで底上げ）

### 見た目の型（contact.jpg より・16:9 長尺）
- 常時 画面の上部にバッジ（「月100万円を削減」「Claude Code×Codexの AI編集スキル解説」）とチャンネルロゴ
- 下部に白字＋黒縁の字幕（1〜2行）。**強調したい一言だけ画面中央に巨大な黄・白文字（黒縁）**で出す（例：「動画編集ができればコンサル案件も取れる」）
- 話者の顔を小窓（右下）に残したまま、スライド・スクショ・資料画像に切り替える（解説パートはほぼこの形）
- 解説スライドは白基調のアニメ（数字カウント、Before/After 並置、3項目カード、アイコン）。結論部分は黒背景カードで切り替え
- 「この動画もAIの声とコードで書いたアニメーションで作っています」＝AI生成部分をあえて見せて訴求にしている

### 私たちに取り入れられる点
1. **スキル化の徹底**：型ごとにスキル分割（今は kaitori-ad-style 1本。型1/型2/ニュース等に分けると再現性UP）
2. **サンプル動画→「その通りに」方式**：上司が選ぶ完成形動画を参考にして指示する運用（LEARNED.md が蓄積先）
3. **強調語だけ巨大テロップ**：DIRECTION_SPEC の「ポジ・実績＝極太・大」と一致。数字・結論語に使う
4. **字幕は意味のまとまりで2行**：既に BudouX で実装済み
5. 全フレーム確認の QA：`ad qa` が既に近い（1秒毎）

### 合わない点・注意
- 長尺 16:9・顔小窓の解説型で、うちの縦型 9:16 広告とは別物（構成ごとの流用は不可）
- 有料スキル（note）は購入していない。中身は動画で語られた概念までしか分からない
- 景表法：「外注費ゼロ」「月100万円削減」のような実績訴求は、うちの広告では根拠・打消し表示が必要
